# MonoFrame

Веб-приложение для подготовки фотографий к печати на форматах 10×15 см и A4.

## Публикация через GitHub Pages

1. Откройте **Settings → Pages**.
2. В разделе **Build and deployment** выберите **Deploy from a branch**.
3. Укажите ветку **main** и папку **/(root)**.
4. Нажмите **Save**.

После публикации приложение будет доступно по адресу:

https://vdovichenkonikita11-netizen.github.io/MonoFrame/

## Файлы приложения

- `index.html` — загрузчик приложения.
- `app-part1.txt` … `app-part5.txt` — сжатые данные приложения, загружаемые браузером при открытии страницы.

Изображения обрабатываются локально в браузере. Для функций ZIP и PDF приложение использует библиотеки, загружаемые с CDN, поэтому для этих функций требуется подключение к интернету.
